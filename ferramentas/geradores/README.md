# geradores

Scripts que geram partes do repositório a partir dos Markdown (galerias, navegação, glossário, flashcards, referências, apostila).

| Conteúdo | Tipo | Descrição |
| --- | --- | --- |
| [`gerar_apostila.py`](gerar_apostila.py) | Python | Gera as apostilas em PDF a partir dos arquivos Markdown do repositório. |
| [`gerar_flashcards.py`](gerar_flashcards.py) | Python | Gera o baralho de flashcards (Anki) em 06 - Revisões e Sínteses/Flashcards/. |
| [`gerar_galerias.py`](gerar_galerias.py) | Python | Gera as galerias dos PDFs originais: cada página vira uma imagem WebP, exibida numa nota Markdown. |
| [`gerar_glossario.py`](gerar_glossario.py) | Python | Gera 07 - Glossário/glossario.md. Os termos ficam na lista E abaixo (também usada pelos flashcards). |
| [`gerar_navegacao.py`](gerar_navegacao.py) | Python | Navegação da base de conhecimento: transforma as pastas do repositório num "caderno" interligado, |
| [`gerar_readmes_aulas.py`](gerar_readmes_aulas.py) | Python | Gera o README.md de cada pasta de aula (índice dos arquivos e navegação). |
| [`gerar_referencias.py`](gerar_referencias.py) | Python | Gera a pasta '08 - Referências e Fontes' (livros.md, artigos.md, README.md, referencias.bib) |
| [`inventario.json`](inventario.json) | JSON |  |
