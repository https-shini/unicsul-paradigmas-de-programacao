# 10 - Caderno de Anotações

Espaço para as **suas** anotações: o que você anotou em aula, dúvidas, explicações com as próprias palavras, fotos do quadro ou do caderno e documentos que quiser anexar. O resto do repositório organiza o material da disciplina; esta pasta é o seu caderno pessoal dentro dele.

## Como usar

| Para… | Faça |
| --- | --- |
| Criar uma anotação | **Add file › Create new file** nesta pasta, com o nome `aaaa-mm-dd-assunto.md`, e copie o [modelo de nota](../00%20-%20Planejamento%20e%20Organização/Modelos/modelo-de-nota.md) |
| Guardar uma foto (quadro, caderno, celular) | **Upload files** na pasta [`imagens/`](imagens/README.md) e cite-a na anotação: `![quadro da aula 12](imagens/2026-11-21-quadro-aula-12.jpg)` |
| Anexar um PDF | Envie o PDF para esta pasta: a galeria com as páginas em imagem é gerada sozinha, ao lado dele |
| Ligar a anotação ao conteúdo | Use links relativos para os resumos e cite páginas como `Aula12 p.13`, que viram links para o slide |

Depois do *commit*, a navegação (trilha, índice desta pasta, *backlinks* e `MAPA.md`) é atualizada automaticamente.

## Exemplo

A [anotação de exemplo](exemplo-de-anotacao.md) mostra uma nota com imagem, código, diagrama, links e citação de slides. Use-a como referência e apague-a quando quiser.

> [!NOTE]
> As anotações desta pasta são suas e podem ter qualquer formato. Ainda assim, vale marcar o que é cópia do material do professor com **[Material original]**, como no restante do repositório.
