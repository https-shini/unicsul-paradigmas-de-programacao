# Imagens do caderno

Fotos e imagens usadas nas anotações. Envie pelo GitHub (**Upload files**) ou copie para esta pasta.

- **Nome:** `aaaa-mm-dd-descricao.jpg` (por exemplo, `2026-11-21-quadro-aula-12.jpg`), sem espaços nem acentos.
- **Formato:** `.jpg` para fotos, `.png` para capturas de tela, `.webp` para imagens leves. O GitHub exibe todos.
- **Tamanho:** fotos do celular costumam ter vários MB. Reduza para cerca de 1600 px de largura antes de enviar; o repositório fica mais leve e as páginas abrem mais rápido.
- **Uso na nota:** `![descrição](imagens/nome.jpg)`, ou `<img src="imagens/nome.jpg" width="600" alt="descrição">` para controlar a largura.
