# Aula 02 — Evolução das Linguagens e Paradigmas · Exercícios

> **[Exercício autoral]** Questões elaboradas a partir de [`Aula02_Evolução_LinguagensDeProgramacao.pdf`](../01%20-%20Slides%20Originais/Aula02_Evolução_LinguagensDeProgramacao.pdf). Resoluções: [`resolucoes-aula-02.md`](../04%20-%20Resoluções/resolucoes-aula-02.md)

## Básico

**E1.** Defina, com as palavras dos slides, (a) linguagem de programação, (b) paradigma e (c) paradigma de programação.

**E2.** Associe cada linguagem ao paradigma indicado na aula: Smalltalk, Prolog, Cobol, Haskell, Ada, C#, Scheme.

**E3.** (Objetiva) Qual característica é apontada como **principal** do paradigma imperativo?
a) Passagem de mensagens  b) Abstração procedural  c) Composição funcional  d) Algoritmo de inferência

## Intermediário

**E4.** Explique a frase "no paradigma OO, os objetos de dados são ativos, e não passivos como no imperativo". Dê um exemplo com uma pilha.

**E5.** Cite e explique as quatro restrições de projeto de uma linguagem. Por que Java é um **contraexemplo** no item "sistemas legados"?

**E6.** O professor afirma que as diferenças entre os programas em Pascal, Java e Prolog vêm de duas fontes. Quais são? Aponte um exemplo concreto de cada fonte nos três códigos.

## Avançado

**E7.** (Interpretação de código) Considere o programa Pascal da p.5 exatamente como está no slide. Qual é a saída para as entradas n1 = 3 e n2 = 6? E para n1 = 2 e n2 = 4? O programa cumpre o enunciado? Corrija-o se necessário.

**E8.** Traduza a regra Prolog `verifica_dobro` para português, objetivo por objetivo, explicando o papel de `:-`, `,`, `is`, `=:=` e `( -> ; )`.

**E9.** Por que não há consenso nas figuras de gerações sobre a 4ª e a 5ª gerações? Monte uma tabela com a posição de **LISP**, **Java** e **SQL** em cada uma das três primeiras figuras.

## Aprofundamento

**E10.** O slide diz que tentativas de projetar máquinas para LISP e Prolog "não deram certo". Relacione essa afirmação com o motivo de linguagens funcionais serem, em geral, interpretadas (Aula 14, p.10) — e avalie se isso vale também para as lógicas e com a ideia de "computador virtual" (Aula 03).

**E11.** Avalie Pascal, C e Python segundo os critérios de legibilidade, facilidade de escrita e confiabilidade (Sebesta 1.3). Justifique cada avaliação com uma característica concreta da linguagem.
