# Aula 07 — Materiais complementares

> Referências completas (ABNT, forma de acesso, links atualizados e BibTeX): [`08 - Referências e Fontes`](../../../08%20-%20Referências%20e%20Fontes/README.md#referências-por-aula).

## Indicados pelo professor

**[Material original]** A aula não traz slide de bibliografia. Pela sequência do curso, valem as referências das aulas vizinhas (Sebesta, caps. 5–6; Tucker & Noonan, cap. 5).

## Selecionados para estudo

**[Complemento]**

- **Sebesta, cap. 6 — "Tipos de dados":** seções sobre tipos enumeração, tipos matriz (incluindo a fórmula de endereçamento de matrizes multidimensionais usada no E7), tipos registro e cadeias de caracteres.
- **Tutorial oficial de Java — "Enum Types":** <https://docs.oracle.com/javase/tutorial/java/javaOO/enum.html>. Mostra que `enum` em Java é uma classe, com métodos e atributos.
- **Tutorial oficial de Java — "Arrays":** <https://docs.oracle.com/javase/tutorial/java/nutsandbolts/arrays.html>. Explica vetores multidimensionais como "vetores de vetores".
