## Modelo para trabalhos futuros

**[Explicação elaborada]** — quando o professor passar um trabalho, crie uma pasta assim:

```text
03 - Trabalhos e Projetos/
└── Trabalho NN - Título curto/
    ├── 01 - Enunciado Original/     ← arquivo do professor, sem alterações
    ├── 02 - Planejamento.md         ← requisitos extraídos do enunciado, divisão de tarefas, prazos
    ├── 03 - Desenvolvimento/        ← código-fonte e documentação
    └── 04 - Entrega/                ← versão final entregue
```

Checklist sugerido para `02 - Planejamento.md`:

- [ ] Requisitos copiados **literalmente** do enunciado, cada um com um identificador (R1, R2…)
- [ ] Linguagem e paradigma exigidos
- [ ] Critérios de avaliação informados pelo professor
- [ ] Prazo e forma de entrega
- [ ] Relação de cada requisito com os conceitos da disciplina (com links para os resumos)
